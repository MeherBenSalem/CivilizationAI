# Smart Villagers AI 1.1.5 verification

Verified locally on Windows, 2 October 2026.

- All three workspaces built with their target JDK: Java 17, 21 and 25.
- Each workspace: 80 passing tests, zero failures/errors, one skipped live DeepSeek test (no account key available).
- Seven exact release jars: initialized mod, stable client screen for 10 seconds, no loading overlay, normal exit, and real HTTP request/response to a local Chat Completions fixture from the loaded release jar.
- HTTP/config tests cover provider presets, NanoGPT subscription routing, custom full/base endpoints, credential selection, malformed config, remote HTTP rejection, safe error handling and token fields.
- Publisher refuses stale boot evidence or jar changes after partial uploads; both failure paths were exercised before publication.
- Review findings were fixed and reviewed again before release.

This verifies client startup and the API contract. It does not authenticate with a real NanoGPT/DeepSeek account, verify a user's billing/subscription, or exercise every model's behavior. NanoGPT's live subscription model catalog was read without authentication; `deepseek-chat` appeared as non-reasoning.

## Reproduce

```powershell
# Set JAVA_HOME_17, JAVA_HOME_21 and JAVA_HOME_25 to your installed JDKs.
.\gradlew.bat buildAll
# Requires minecraft-launcher-lib; observer code is test-only and excluded from jars.
python scripts/smoke-client.py --version 1.1.5
node scripts/upload_platforms.mjs --dry-run
```

An optional `SMARTVILLAGERS_MINECRAFT_CACHE` environment variable lets the client tester reuse an existing verified Minecraft/loader installation cache. Test instances and dummy API keys stay under `.cache/smart-villagers-tests` in your home directory.
