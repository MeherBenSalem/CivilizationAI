## Gradle run boots (client + dedicated server)

Success for servers means `Initializing Smart Villagers AI`, `Smart Villagers AI ready`, and vanilla `Done (` with no mod crash.

Success for 1.20.1 / 1.21.1 / 26.2 clients means the same init lines plus a working LWJGL window backend.

Minecraft 26.3 switched the client window stack to SDL. On this agent VM both 26.3 clients load the mod, then vanilla fails with `Couldn't find matching GLX visual` (OpenGL) and missing `VK_KHR_surface` (Vulkan). That is an environment renderer limit, not a Smart Villagers crash. Dedicated 26.3 servers booted cleanly.
